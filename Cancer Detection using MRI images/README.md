# Assignment 5: Cancer Detection using MRI Images

## Overview
This project implements a Convolutional Neural Network (CNN) built with PyTorch to classify MRI scans for cancer detection. 

## Technical Details
* **Framework**: PyTorch
* **Architecture**: Multi-layer CNN with Max Pooling and ReLU activation
* **Data**: Utilizes a programmatic dataset pipeline for standardized grayscale MRI processing.

## How to Run
```bash
python 05_cancer_detection.py
