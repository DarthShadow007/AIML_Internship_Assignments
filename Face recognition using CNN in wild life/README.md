# Assignment 6: Face Recognition Using CNN in Wildlife

## Overview
This project implements a Convolutional Neural Network (CNN) in PyTorch for individual wildlife face recognition across species.

## Technical Architecture
* **Framework**: PyTorch
* **Model Type**: Deep Convolutional Neural Network (CNN)
* **Features**: Multi-layer feature extraction with Max Pooling and ReLU activations for high-dimensional spatial feature representation.

## How to Run
```bash
python 06_face_recognition.py
