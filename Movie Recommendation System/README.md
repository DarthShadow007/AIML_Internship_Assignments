# Assignment 2: Movie Recommendation System

## Overview
This project builds a collaborative filtering recommendation system using Singular Value Decomposition (SVD) on the MovieLens 100K dataset. It outputs prediction RMSE and generates top-10 personalized movie recommendations for sample users.

## Files
* `02_movie_recommendation.py`: Python script handling automated dataset fetching, matrix factorization/SVD, and recommendation generation.

## How to Run
python 02_movie_recommendation.py
